Happy Path (things that should work):

Calculate bonus as MANAGER — POST with valid data
Calculate bonus as ADMIN — POST with valid data
Employee views own bonuses — GET /bonus/my
Admin views all bonuses — GET /bonus/all

Validation Tests (things that should fail correctly):

Duplicate review — same employeeId + same year = 409 Conflict
Employee not found — wrong employeeId = 404 Not Found
Invalid KPI score — taskCompletion: 30 (over max 25) = 400 Bad Request

Security Tests (role based):

EMPLOYEE tries to calculate bonus — should get 403 Forbidden
MANAGER tries to view all bonuses — should get 403 Forbidden
Wrong password — should get 401 Unauthorized







Here are all 10 tests:

---

### Happy Path Tests

**Test 1 — MANAGER calculates bonus**
- Method: `POST`
- URL: `http://localhost:8080/api/performances/calculate`
- Auth: Basic Auth — `bob` / `password123`
- Body:
```json
{
    "employeeId": 3,
    "reviewYear": 2025,
    "taskCompletion": 20,
    "attendance": 10,
    "teamCollaboration": 10,
    "problemSolving": 10,
    "communication": 7,
    "leadership": 7,
    "clientSatisfaction": 7
}
```
**Expected:** 200 OK
```json
{
    "employeeId": 3,
    "employeeName": "Carol White",
    "category": "Silver Tier",
    "bonusPercentage": 12.0,
    "bonusAmount": 10800.00,
    "totalCompensation": 100800.00
}
```

### Validation Tests

**Test 5 — Duplicate review**
- Method: `POST`
- URL: `http://localhost:8080/api/performances/calculate`
- Auth: Basic Auth — `bob` / `password123`
- Body: exact same as Test 1 (same employeeId: 3, reviewYear: 2025)

**Expected:** 409 Conflict
```json
{
    "error": "Review already exists for employee 3 for year 2025"
}
```

---
